# Security and privacy reports

This public repository contains only a static product case study. It does not contain the production application source, curriculum, learner accounts or learner data.

If you find a security or privacy issue in the showcase or in the linked product experience, use this repository's **Security → Report a vulnerability** form. Please do not open a public issue for a vulnerability.

Include only the minimum information needed to reproduce the problem. Never attach or paste:

- a course progress backup;
- journal text or learner evidence;
- a private repository or project URL;
- a password, token, recovery code or sign-in link;
- client, employer or personal records.

Reports will be acknowledged when reviewed. This is an independently maintained pilot project and does not offer 24-hour security support.
